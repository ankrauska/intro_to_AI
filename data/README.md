# Data

**No identifiable patient data here.** No names, CPR numbers, dates of birth, addresses, free-text case descriptions, or recordings.

Two ways to use this folder:

1. **Anonymized data.** Put the anonymized file here. "Anonymized" means it cannot be linked back to a person, even with other information. This is a higher bar than removing names. If in doubt, it is not anonymized.
2. **Only a pointer.** Leave the data where it is allowed to live (a secure server, a region drive). Write below where it is and who may access it. The analysis scripts run there, and only the results come back to `analysis/output/`.

Nothing in this folder is committed to git except this README (see `.gitignore`).

**This folder is read-only.** Scripts read from it and never write to it. Recoding happens in the analysis script, on read.
