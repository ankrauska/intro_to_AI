# Statistical analysis plan (SAP)

The statistical analysis plan, one file per section. Drafted with the `draft-sap` skill once the protocol is final.

The SAP follows Gamble et al. 2017 (content of a SAP) and the estimand framework in ICH E9(R1). `../writing/completeness_checklist.md` sections B, C and F are the SAP's own checks.

## Drafts and comments

Same workflow as `manuscript/`: first drafts go to `llm_originals/`, you edit the section file, and comments go inline as `XX ... XX`.

## Locking

The SAP is locked **before anyone sees outcome data by group**. After that, Claude does not edit files in this folder. Any change is an amendment, logged in `plan.md`, and the manuscript reports it as a deviation.
